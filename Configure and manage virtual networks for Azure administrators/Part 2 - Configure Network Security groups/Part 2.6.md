## 🖥️ Deploy via Azure Portal (Short)

1. Go to **Azure Portal**
2. Search: **"Deploy a custom template"**
3. Upload or paste `azuredeploy.json`
4. Enter parameters → Click **Review + Create**

---

## 📌 Notes

- ✅ JSON must be valid  
- 📐 Parameters must match schema  
- 🧪 Use `az deployment group validate` to test before deploying
