# 🔐 Azure Role-Based Access Control (RBAC) - Exam-Level Summary

## 📘 Introduction
- ✅ Cloud security is critical—protect VMs, websites, networks, and storage in Azure.
- ✅ **Azure RBAC** (Role-Based Access Control) manages **who** has access, **what** they can do, and **where** they can access.
- ✅ Helps balance **security** and **productivity** by allowing appropriate access to employees and partners.

## 🏢 Real-World Scenario
- Company: **First Up Consultants** – Engineering firm specializing in circuit & electrical design.
- Migrated workloads to Azure to improve **collaboration** across teams and locations.
- Role: As an IT Admin, you're responsible for:
  - Securing company assets.
  - Ensuring correct access permissions to resources.
- Solution: Use **Azure RBAC** to assign and manage access levels efficiently.

## 🎯 Learning Objectives

### ✅ Verify Access
- Check **your** permissions on Azure resources.
- Audit **others'** access using built-in tools and command-line.

### ✅ Grant Access
- Assign roles to **users**, **groups**, or **service principals**.
- Use **least privilege principle**—grant only necessary permissions.
- Apply roles at **subscription**, **resource group**, or **resource** level.

### ✅ View Activity Logs
- Monitor changes made to access roles via **Azure Activity Logs**.
- Ensure visibility and accountability of access modifications.

---

📝 **Pro Tip for Exams**:
- Remember: Azure RBAC **only manages authorization**, not authentication.
- Common roles:
  - **Owner** – Full access, including role assignments.
  - **Contributor** – Manage everything except role assignments.
  - **Reader** – View only.
