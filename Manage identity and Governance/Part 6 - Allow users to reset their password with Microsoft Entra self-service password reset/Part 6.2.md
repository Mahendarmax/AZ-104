![image](https://github.com/user-attachments/assets/cd1c5df8-39ec-408b-a21d-2645182fd3da)# 🧪 Exercise - Set Up Self-Service Password Reset (SSPR)

## 🎯 Goal:
Configure, register, and test SSPR using a non-admin user and email authentication.

---

## 🔹 Step 1: Create a Security Group

<img src="https://github.com/user-attachments/assets/20f88ce7-2e59-43bb-ad02-960c39d34923" width="600">



- Navigate to: `Microsoft Entra ID > Manage > Groups`
- Click: **+ New Group**
- Fill out:
  - **Group type**: Security  
  - **Group name**: SSPRTesters  
  - **Description**: Members are testing the rollout of SSPR  
  - **Membership type**: Assigned
- Click: **Create**

---

## 🔹 Step 2: Create a Test User

- Navigate to: `Microsoft Entra ID > Manage > Users`
- Click: **+ New user > Create new user**
- Fill out:
  - **User principal name**: `balas`
  - **Display name**: `Bala Sandhu`
  - **Password**: Copy the autogenerated password to Notepad
- Assign the user to the group:
  - Go to **Assignments tab > Add group**
  - Select `SSPRTesters`
- Click: **Review + Create > Create**

---

## 🔹 Step 3: Enable SSPR for the Group

![image](https://github.com/user-attachments/assets/7b930a73-2969-4bcc-9128-6f10c496d103)


- Navigate to: `Microsoft Entra ID > Password reset > Properties`
- Set:  
  - **Self-service password reset enabled** → `Selected`
  - **Select Group** → `SSPRTesters`
- Click: **Save**

---

## 🔹 Step 4: Review & Customize Settings

- Go to:
  - **Authentication methods** → Ensure **Email** is selected
  - **Registration** → Leave default
  - **Notifications** → Leave default
- Under **Customization**:
  - Enable: ✅ `Yes`
  - Helpdesk contact: `admin@<organization-domain>.onmicrosoft.com`
- Click: **Save**

---

## 🔹 Step 5: Register for SSPR

![image](https://github.com/user-attachments/assets/04074acd-d994-4952-bb7c-d585470101fe)


- Open private/incognito window
- Go to: `https://aka.ms/ssprsetup`
- Sign in as: `balas@<organization-domain>.onmicrosoft.com`
- Set new password if prompted
- Go to: **Security info > + Add sign-in method**
- Select: **Email**
- Enter alternate email and verify using email code

---

## 🔹 Step 6: Test SSPR

<img src="https://github.com/user-attachments/assets/351aaa21-ef9d-4cd3-98a3-50e73700942b" width="600">
"

- Open a new incognito browser window
- Go to: `https://aka.ms/sspr`
- Enter user ID: `balas@<organization-domain>.onmicrosoft.com`
- Complete CAPTCHA > Select: **Email**
- Enter verification code received via email
- Set new password and click **Finish**

---

## 📌 Key Notes for Exam

- Group-based rollout ensures limited testing.
- Always test with **non-admin** users.
- Use **Email** as an authentication method for simplicity.
- Private/incognito mode helps bypass cached session errors.
- `https://aka.ms/ssprsetup` → Registration  
  `https://aka.ms/sspr` → Password Reset
