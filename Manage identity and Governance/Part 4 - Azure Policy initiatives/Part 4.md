# 📘 Azure Policy - Exam Essentials

## 📋 Common Azure Policy Examples

| Policy Name | Purpose |
|-------------|---------|
| Allowed Locations | Restrict resource deployment to specific Azure regions |
| Allowed Resource Types | Restrict which Azure resources can be deployed |
| Tag Enforcement | Ensure specific tags are applied to resources |
| Enforce Naming Convention | Enforce a standard naming pattern for resources |
| Inherit Tags | Automatically inherit tags from the resource group |
| Audit VMs without Managed Disks | Identify VMs not using managed disks |
| Require Secure Transfer for Storage | Ensure secure transfer is enabled on storage accounts |
| Deploy Diagnostic Settings | Automatically deploy monitoring settings to supported resources |

---

## ✅ What is Azure Policy?
- Governance service to **create, assign, and manage rules** across Azure resources.
- Ensures compliance with **organizational standards and SLAs**.
- Policies are defined using **JSON** files known as **policy definitions**.

---

## 🎯 What are Azure Policy Initiatives?
- **Initiatives** = A group of related policies bundled together.
- Helps enforce **multiple policies under a common goal**.
- Useful for ensuring **regulatory compliance** in industries like government, healthcare, and finance.

---

## 🛠️ Common Use Cases
- Assign a policy to **enforce conditions** for future resource deployments.
- Create and assign an initiative to **track compliance** across many resources.
- Resolve a **noncompliant or denied resource**.
- Apply a new policy **organization-wide** using initiatives.
