# 🧪 What is Microsoft Learn Sandbox?

The **Microsoft Learn Sandbox** is a free, temporary Azure environment provided during Microsoft Learn exercises.  
It lets you **explore and practice Azure services** without needing your own subscription or incurring any cost.

When you activate the sandbox, a **temporary Azure subscription** is created and linked to your account.  
This allows you to safely perform exercises using Azure CLI, PowerShell, or the Azure Portal in a controlled environment.

---

# 🔄 Microsoft Learn Sandbox - Usage Guide

## ⏱️ How Many Times Can I Use It?
- ✅ Unlimited activations per day  
- ⏳ Only **one active session at a time**  
- ⏲️ Each session lasts about **1 hour**  
- 🔁 You can **reactivate** after each session ends  

---

## 🎯 When to Use the Sandbox
- 📘 Completing **Microsoft Learn modules**
- 💻 Practicing **Azure CLI / PowerShell commands**
- 🧪 Testing **basic Azure services** like:
  - Resource Groups
  - Virtual Machines (small sizes)
  - Storage Accounts
  - Web Apps

---

## ⚠️ Limitations
- 🚫 Not all Azure services are available (e.g., premium VMs, advanced networking)
- 📦 Limited to what the module allows
- 🧹 **Resources are temporary** and automatically deleted after the session
- 🔐 Limited permissions — you may not have full Azure role access
